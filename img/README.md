# 🌱 Agrinho 2026

Projeto desenvolvido para o programa **Agrinho 2026**, com o objetivo de conscientizar e demonstrar a importância da conexão entre o campo e a cidade, destacando a sustentabilidade, a tecnologia e a valorização do trabalho rural.

## 📖 Sobre o Projeto

O Agrinho 2026 é uma aplicação web interativa criada para apresentar informações educativas sobre:

- Relação entre campo e cidade;
- Sustentabilidade ambiental;
- Produção agrícola;
- Inovação e tecnologia no campo;
- Importância do agronegócio para a sociedade.

O projeto busca proporcionar uma experiência moderna e acessível para estudantes, professores e visitantes.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- React
- Next.js
- Vercel

## ✨ Funcionalidades

- Interface responsiva
- Navegação intuitiva
- Conteúdo educativo
- Design moderno
- Compatível com dispositivos móveis
- Animações e elementos interativos
